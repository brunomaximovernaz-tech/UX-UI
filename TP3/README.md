# TP3 - Trabajo Práctico: HTML y CSS (20 Ejercicios)
**Materia:** Diseño UX-UI - 2026  
**Carrera:** Licenciatura en Sistemas de Información (UADER FCyT - Concepción del Uruguay)

## Descripción
Este repositorio contiene la resolución de los 20 ejercicios prácticos de HTML5 y CSS3, organizados por bloques de dificultad (Básico, Intermedio y Medio/Avanzado).

## Estructura
Cada ejercicio está contenido en su respectiva carpeta (`ejercicio-01` a `ejercicio-20`) y cuenta con:
- `index.html`: Estructura semántica en HTML5.
- `styles.css`: Estilos visuales con CSS3 (Flexbox, CSS Grid, variables, media queries y animaciones).
